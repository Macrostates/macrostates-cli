# Start this project with Macrostates

This repository will follow [Macrostates](https://github.com/Macrostates).

For an explicitly requested project kickoff, begin by cloning
`git@github.com:Macrostates/macrostates-meta.git` into a temporary working location.
If the website appears empty, unavailable or inaccessible, still try the clone:
the definer may have repository access that is unavailable through the website.

Read the cloned package's `README.md`, follow its reading order, and use
`annex_project-kick-off.md` to prepare this project's specification composition.
